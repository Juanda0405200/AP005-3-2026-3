¿Qué es la programación aplicada en electrónica?

La programación aplicada en electrónica consiste en escribir código que controla, lee o comunica componentes y circuitos físicos. En lugar de producir solo programas para una pantalla, el código interactúa con el mundo real: enciende LEDs, mide temperatura, mueve motores o envía datos por internet. Normalmente se ejecuta en microcontroladores como Arduino, ESP32 o Raspberry Pi Pico.

Ejemplos de cómo se usa:

  • Lectura de sensores: programar un ESP32 para leer la temperatura y la humedad de un sensor DHT22 y mostrarlas en una pantalla.
  • Control de actuadores: activar un relé o un motor cuando un sensor detecta movimiento o poca luz.
  • Internet de las cosas (IoT): enviar los datos medidos por WiFi a una plataforma en la nube para verlos desde el celular.
  • Automatización: un sistema de riego que se activa solo cuando la humedad del suelo baja de cierto valor.
  • Análisis de datos: guardar las mediciones de los sensores y analizarlas con Python para encontrar patrones o predecir fallas.
